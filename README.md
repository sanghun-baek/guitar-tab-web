# Guitar TAB 웹판

기타 TAB 악보를 실시간으로 찍고, 고치고, 저장하는 편집기의 웹판입니다.

- 바로 쓰기: https://sanghun-baek.github.io/guitar-tab-web/
- 이 저장소에는 빌드 결과만 있습니다. 소스는 비공개입니다.
- 곡은 이 컴퓨터의 파일(.gtab)로만 열고 저장하며, 어디로도 보내지 않습니다.
  Chrome·Edge는 연 파일에 바로 저장하고, 그 밖의 브라우저는 다운로드로 내려받습니다.
- MusicXML(.musicxml·.xml·.mxl)과 Guitar Pro 7·8(.gp) 파일도 열어서 가져올 수 있습니다 (브라우저 안에서만 읽음).
- 키보드 중심 편집기라 휴대폰·태블릿은 지원하지 않습니다. 단축키는 화면에서 F1.
